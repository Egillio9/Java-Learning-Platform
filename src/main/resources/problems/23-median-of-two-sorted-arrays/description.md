Given two sorted arrays `nums1` and `nums2`, return the **median** of all their elements combined.

The answer is checked to 5 decimal places. The intended solution runs in `O(log(m + n))`.

**Example 1**

```text
Input:  nums1 = [1,3], nums2 = [2]
Output: 2.00000
```

**Example 2**

```text
Input:  nums1 = [1,2], nums2 = [3,4]
Output: 2.50000
```

**Constraints**

- `0 <= m, n <= 1000`
- `1 <= m + n <= 2000`
- `-10^6 <= nums1[i], nums2[i] <= 10^6`
