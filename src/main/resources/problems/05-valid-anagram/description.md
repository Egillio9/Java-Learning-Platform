Given two strings `s` and `t`, return `true` if `t` is an **anagram** of `s` (it uses exactly the same letters, the same number of times), and `false` otherwise.

**Example 1**

```text
Input:  s = "anagram", t = "nagaram"
Output: true
```

**Example 2**

```text
Input:  s = "rat", t = "car"
Output: false
```

**Constraints**

- `1 <= s.length, t.length <= 5 * 10^4`
- `s` and `t` contain lowercase English letters.

**Follow-up:** What changes if the strings may contain any Unicode characters?
