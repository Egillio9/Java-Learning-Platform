Given a string `s`, return the length of the longest **substring** (a contiguous block of characters) in which no character repeats.

**Example 1**

```text
Input:  s = "abcabcbb"
Output: 3
```

**Example 2**

```text
Input:  s = "bbbbb"
Output: 1
```

**Example 3**

```text
Input:  s = "pwwkew"
Output: 3
```

**Constraints**

- `0 <= s.length <= 5 * 10^4`
- `s` may contain letters, digits, symbols and spaces.
