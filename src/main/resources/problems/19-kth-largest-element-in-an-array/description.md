Return the `k`-th largest element of `nums`: the element that would be at position `k` if the array were sorted in **descending** order (duplicates count separately).

Try to beat a full sort.

**Example 1**

```text
Input:  nums = [3,2,1,5,6,4], k = 2
Output: 5
```

**Example 2**

```text
Input:  nums = [3,2,3,1,2,4,5,5,6], k = 4
Output: 4
```

**Constraints**

- `1 <= k <= nums.length <= 10^5`
- `-10^4 <= nums[i] <= 10^4`
