Return the values of a binary tree level by level: a list per level, left to right within each level, starting from the root.

**Example 1**

```text
Input:  root = [3,9,20,null,null,15,7]
Output: [[3],[9,20],[15,7]]
```

**Example 2**

```text
Input:  root = [1]
Output: [[1]]
```

**Example 3**

```text
Input:  root = []
Output: []
```

**Constraints**

- The number of nodes is in the range `[0, 2000]`.
