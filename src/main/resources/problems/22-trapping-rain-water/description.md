`height` describes an elevation map where each bar is 1 unit wide. Compute how many units of rain water are trapped between the bars after it rains.

**Example 1**

```text
Input:  height = [0,1,0,2,1,0,1,3,2,1,2,1]
Output: 6
```

**Example 2**

```text
Input:  height = [4,2,0,3,2,5]
Output: 9
```

**Constraints**

- `1 <= height.length <= 2 * 10^4`
- `0 <= height[i] <= 10^5`
