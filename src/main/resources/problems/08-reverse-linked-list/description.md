Given the `head` of a singly linked list, reverse the list and return the new head.

**Example 1**

```text
Input:  head = [1,2,3,4,5]
Output: [5,4,3,2,1]
```

**Example 2**

```text
Input:  head = [1,2]
Output: [2,1]
```

**Example 3**

```text
Input:  head = []
Output: []
```

**Constraints**

- The number of nodes is in the range `[0, 5000]`.
- `-5000 <= Node.val <= 5000`

**Follow-up:** Solve it both iteratively and recursively.
