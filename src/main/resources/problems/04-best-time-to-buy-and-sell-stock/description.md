`prices[i]` is the price of a stock on day `i`. You may buy once and sell once, on a **later** day than you bought.

Return the maximum profit you can make. If no profit is possible, return `0`.

**Example 1**

```text
Input:  prices = [7,1,5,3,6,4]
Output: 5
```

**Example 2**

```text
Input:  prices = [7,6,4,3,1]
Output: 0
```

**Constraints**

- `1 <= prices.length <= 10^5`
- `0 <= prices[i] <= 10^4`
