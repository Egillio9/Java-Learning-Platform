Return an array `answer` where `answer[i]` is the product of every element of `nums` **except** `nums[i]`.

Solve it in `O(n)` time **without using division**. All products fit in a 32-bit integer.

**Example 1**

```text
Input:  nums = [1,2,3,4]
Output: [24,12,8,6]
```

**Example 2**

```text
Input:  nums = [-1,1,0,-3,3]
Output: [0,0,9,0,0]
```

**Constraints**

- `2 <= nums.length <= 10^5`
- `-30 <= nums[i] <= 30`

**Follow-up:** Can you use only O(1) extra space, not counting the output array?
